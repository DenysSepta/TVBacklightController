01 — Interaction

Two buttons.
One less menu.

The app listens for remote key events through Android's Accessibility service, adjusts its tracked level in small steps, and shows a temporary overlay while you make the change.

INPUT / 01

Press Channel Up or Down

Use a compatible remote while watching content or navigating other apps on the TV.

CONTROL / 02

Adjust in 5% steps

A press changes the app's tracked level; holding the button repeats the adjustment. The value stays within 0–100%.

FEEDBACK / 03

See the temporary overlay

The on-screen indicator shows the value tracked by the app and disappears after about three seconds.

02 — Under the hood

Lightweight by design.
Honest about limits.

The project writes Android's global picture_backlight setting. It doesn't capture video, analyze the image, or generate ambient lighting. Whether the panel responds depends on the TV's firmware.

↗   Remote integration

Accessibility key events

Uses Android's Accessibility service to detect Channel Up/Down events when the TV exposes them to the service.

↗   System setting

Global backlight value

Requires the privileged WRITE_SECURE_SETTINGS permission, granted through ADB during setup.

↗   Persistent service

Boot and screen handling

Attempts to start its service on boot and when the screen turns on, subject to firmware background-service restrictions.

↗   On-screen feedback

Temporary level indicator

Displays the app's tracked percentage in an accessibility overlay. The indicator is not a hardware brightness measurement.

Compatibility note

Tested by the maintainer on a Xiaomi Android TV; other models and firmware are not yet confirmed. The app starts its internal value at 50% rather than reading the panel's current setting, and some TVs may ignore picture_backlight or use vendor-specific controls.

03 — Quick start

Build it.
Install it.
Grant access.

Build the Android app, install it over ADB, grant the required system permission, then enable the TV Backlight Accessibility service on the device.

Full installation guide ↗Troubleshooting ↗
# Build the debug APK
./gradlew assembleDebug

# Connect and install (replace TV_IP)
adb connect TV_IP:5555
adb install app/build/outputs/apk/debug/app-debug.apk

# Grant permission required for backlight writes
adb shell pm grant com.tv.backlight android.permission.WRITE_SECURE_SETTINGS
